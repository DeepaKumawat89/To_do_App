## ✨ Overview

The ToDo App is a clean and user-friendly task management application built using Flutter.  
It allows users to create, manage, and track daily tasks efficiently with a minimal and modern interface.

This project focuses on state management, user interaction handling, and structured UI design in Flutter.

---

## 🚀 Features

- ➕ Add New Tasks  
- ✅ Mark Tasks as Completed  
- 🗑️ Delete Tasks  
- 📋 View Task List  
- 🔄 Real-time UI Updates  
- 📱 Responsive & Clean Design  

---

## 🛠️ Tech Stack

- **Flutter**
- **Dart**
